# CSV Lead Validation & Data Cleaning Tool

## Author
**Jahid, whatsapp: 8801309495010**

A Python-based data processing tool that validates lead information from CSV files, detects duplicate leads, identifies invalid records, and exports clean, invalid, and duplicate data into separate CSV files.

## Overview

Managing lead data from multiple sources often results in duplicate records, invalid contact information, missing values, and inconsistent data formats.

This project automates the lead validation and data cleaning process using Python. It reads lead records from a CSV file, validates email addresses, phone numbers, and amounts, identifies duplicates, tracks validation errors, and generates separate output files for further analysis.

## Features

- **CSV Processing:** Read structured lead data using Python's built-in `csv` module.
- **Email Validation:** Validate email addresses using a custom `EmailValidation` module.
- **Phone Number Validation:** Validate phone numbers using the `phonenumbers` library with Bangladesh as the default parsing region.
- **Duplicate Detection:** Identify duplicate leads based on email addresses and phone numbers.
- **Amount Validation:** Detect missing or non-numeric amount values.
- **Invalid Record Tracking:** Record validation errors and associate them with the corresponding lead.
- **Data Categorization:** Separate records into valid, invalid, and duplicate categories.
- **CSV Export:** Generate individual CSV files for cleaned, invalid, and duplicate leads.
- **Summary Report:** Display total leads and category counts in the terminal.

## Input CSV Format

The input file, `input_leads.csv`, should contain the following columns:

```csv
lead_id,name,email,phone,country,amount
L001,John Doe,john@example.com,01712345678,Bangladesh,500
L002,Jane Smith,jane@example.com,01812345678,Bangladesh,750
L003,Alex Brown,invalid-email,01712345678,Bangladesh,abc
```

Ensure that the CSV column names match the field names expected by the program.

## Output Files

After successful execution, the program generates three CSV files.

### 1. `Clean_leads.csv`

Contains leads that pass the implemented validation checks and are not identified as duplicates.

### 2. `Invalid_leads.csv`

Contains leads with validation problems, such as:

- Invalid email addresses
- Blank email addresses
- Invalid phone numbers
- Blank phone numbers
- Missing or invalid amount values

The `Reason` field records the validation issue or issues associated with each lead.

### 3. `Duplicate_leads.csv`

Contains leads identified as duplicates based on email addresses or phone numbers.

The `Duplicate by` field indicates which field triggered duplicate detection.

## How It Works

1. Read lead records from the input CSV file.
2. Normalize email addresses and trim surrounding whitespace from phone numbers.
3. Validate email addresses.
4. Validate phone numbers using the `phonenumbers` library.
5. Check whether amount values can be converted to numeric values.
6. Track invalid records and their associated reasons.
7. Detect duplicate emails and phone numbers.
8. Categorize the processed leads.
9. Export the results into separate CSV files.
10. Print a summary report in the terminal.

## Error Handling

## Limitations

- The input CSV file must contain the expected column names.
- Phone number parsing uses Bangladesh (`BD`) as the default region.
- Email validation depends on the implementation of the custom `pyShir_email` module.
- Duplicate matching currently uses email addresses and phone numbers.
- Amount validation can be improved with additional business rules, such as rejecting negative or non-finite values.
- Duplicate and invalid records may overlap depending on the classification rules.
